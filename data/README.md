# Local data layout

Large biological data are intentionally **not versioned in Git**. The repository expects this layout:

```text
data/
├── methylation/
│   └── tcga_array_official_full.h5
├── cpg/
│   └── registries/
│       ├── array_cpg_map.parquet
│       ├── epic_cpg_map.parquet
│       └── wgbs_cpg_map.parquet
├── derived/
│   └── ntv3_pre_chr1_atlas/
│       └── chr1_ntv3_pretrain_atlas_v1.h5
├── external/
│   └── functional/
│       ├── locus_features_v1 -> ../../../../MehylPredictor/local_methyl_data/derived/locus_features_v1
│       └── checkpoints/
│           └── functional_encoder.pt -> ../../../../../MehylPredictor/.../checkpoints/last.pt
├── cache/
│   └── representations/
│       └── functional_annotations_chr1.h5     # generated by this repo
├── protocols/
│   └── tcga_array_chr1_masking_seed17_holdout20.npz
└── local_manifest.json                        # generated preflight report
```

The actual symlink targets are host-dependent; the arrows above are conceptual examples.

## Current benchmark scope

The first controlled benchmark is deliberately restricted to **chr1**, because the available NTv3-pre atlas currently covers chr1 only. Both Functional and NTv3-pre arms therefore use the same TCGA-array chr1 universe and the same persisted locus split.

Do not silently use genome-wide functional loci against a chr1 NTv3 atlas. The runner records and validates chromosome scope.

## Bootstrap

From the repository root:

```bash
python scripts/bootstrap_local_data.py
```

The script:

1. validates the TCGA methylation matrix and array CpG registry;
2. auto-detects the CpG-ID and embedding datasets in the existing NTv3-pre atlas;
3. measures NTv3 coverage of the TCGA chr1 universe;
4. creates symlinks to the existing MehylPredictor functional locus store and functional encoder checkpoint;
5. writes `data/local_manifest.json`.

It exits non-zero if the NTv3 atlas does not cover the complete dataset-defined chr1 universe. This is intentional: a representation is not allowed to receive a silently reduced/easier test set.
