## 8. Caveats (from `docs/REGULATORY_CONFIRMATION_FAIRNESS.md`)

- Native dimensions differ (candidate 256, functional 256, CpGPT-large 512, DeepCpG 128); adapter capacity grows with dimension; no dimension matching in this result.
- Fit scope: candidate SVD fit on chr1-19 loci only; functional SVD fit on all 408,399 loci (transductive); CpGPT/DeepCpG external.
- dtype: candidate float32, others float16.
- The candidate has 849 all-zero rows (no track overlap).
- Functional includes dense genomic-context inputs (part of the functional input, not independent validation); the candidate has none.
- CpGPT and DeepCpG encoders were pretrained on methylation (external); the candidate was not.
- Seeds change only the reconstructor init (masks/panels identical); n = 3; validation patients are the same for all arms and were used for checkpoint selection (best epoch), so these numbers are not an untouched test estimate.
- Modern sequence FMs are not part of Phase A.
